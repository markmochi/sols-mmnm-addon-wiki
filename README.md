# Sol’s MMNM Addon guide

[Read the guide](https://markmochi.github.io/sols-mmnm-addon-wiki/)

A guide for server owners, admins, and players using Sol’s MMNM Addon on Minecraft 1.16.5 and 1.20.1. It covers command changes, protected areas, ability rules, spawning, profiles, messages, music, weather, restoration, snapshots, configuration, and troubleshooting.

Open a topic to read just the part you need. The site also includes commands you can copy and a quick setup example.
